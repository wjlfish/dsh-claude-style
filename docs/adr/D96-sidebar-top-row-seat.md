# D96. 侧栏顶行的座位交给第三方插件，隐藏的侧栏从红绿灯旁的打开按钮探出

## 背景

Claude Code Desktop 把 Cowork / Code 开关放在标题栏下的一行，折叠按钮与红绿灯同处标题栏左侧；侧栏隐藏时，指针停在打开按钮上就会把侧栏探出来，移开后收回。DSH 的宿主把这一行画成品牌行，只留给自己的品牌与折叠按钮，没有给第三方面板的座席；macOS 桌面壳隐藏侧栏时整列卸载，折叠按钮与打开按钮不是同一个节点。

本项目这一侧要复刻的是同一个结构：项目对话 / 非项目对话的标签条应当站在这行，活动入口挨着折叠按钮，品牌不再出现在顶行，隐藏后的侧栏要从红绿灯旁的打开按钮探出。

## 决定

- 皮肤在侧栏顶行里放一个稳定、空的座位节点，用皮肤自己的属性 `data-dsh-claude-sidebar-tabseat` 标记，并把该属性作为跨插件的契约：第三方插件把自己的标签条 portal 进这个节点。座位不是 `data-dsh-claude-part`，因为 part 属性归标记遍历所有，每一趟会被重写。
- 座位为空时它不显示，macOS 桌面布局连整行都不画；座位里有内容时皮肤在 `<body>` 上写 `data-dsh-claude-sidebar-tabs`，样式表把这一行画成开关行。品牌在两种布局里都让位。
- 皮肤把 macOS 桌面壳顶条的折叠按钮放到红绿灯右缘（`--dsh-claude-page-zoom-factor` 换算成页面像素），隐藏侧栏时宿主挂在同一位置的打开按钮用同一段偏移，探出与收起的按钮因此重合。红绿灯的中心固定在窗口顶下 24px、按钮组从 16px 开始，所以按钮的顶边是 `24 / 缩放 - 14` 页面像素；横向让按钮左缘落在 88 物理像素处。
- 侧栏列是 `position: relative`，这是给第三方插件顶行控制（活动铃铛）的定位锚点：控制以列内偏移摆放，列的展开、收起、探出动画都带着它走，动画期间的重新测量也只读到同一变换下两个盒子的差，不会把控制放到屏幕外。
- 探出是覆盖层而不是重排：皮肤在探出期间把宿主的列宽过渡关掉，列的进出用 `transform` 动画，并保持桌面壳原来的 leading inset（`--dsh-frame-leading-clearance`），所以指针停在打开按钮上时，页面其它部分的位置与尺寸不变。出现动画取 150ms 的 surface 时长与 damped-out 曲线，指针停留判定的等待取 80ms，探出因此比原来 250ms + 120ms 的等待更快。
- 顶部同一条标题栏里，会话标题行也按窗口按钮的实际像素对齐：宿主把 40px 高、上内边距 10px 的标题栏按页面缩放绘制，标题行的中心会随缩放离窗口按钮越来越远；皮肤把标题栏高度与上内边距按 `24 / 缩放` 重算，标题行中心始终落在窗口按钮的 24px 中心线上，并在标题栏底部留出 10px 空气，关闭边线不贴住标题。
- 侧栏收起时宿主把标题行向右让开红绿灯旁的两个控件，那份让位（`--dsh-frame-leading-clearance`）同样是页面长度：0.8 缩放下控件会越过它压到标题上。皮肤按同一套几何把它重算为 `88 / 缩放 + 72` 页面像素（两个 28px 控件加 8px 间隙，正是宿主在 1 倍缩放下的 160px），标题与新建会话按钮之间保持 8 页面像素。
- 「指针停在按钮上探出侧栏」的判定同时接受侧栏自己的折叠按钮和桌面壳的打开按钮；隐藏侧栏的那一次按下会暂时压住探出，指针离开按钮后再停上去才会弹出。
- 侧栏折叠按钮的契约选择器从「顶行最后一个按钮」改为任意位置的 `sidebar-toggle` part，两个把按钮画在不同位置的布局共用一条契约。
- 分段控件比 Claude Code 自己的 32px 控件再高一档（36 页面像素），所在行同步从 46px 加到 54px（控件 36 + 上下各 8 的留白），0.8 页面缩放下控件约 28.8 物理像素；这是按读者「整体再大一点」的反馈做的取舍，行高与控件高度由同一份几何推导，后续再调尺寸时两者一起改。

## 后果

- 第三方插件不必修改宿主、也不必抢宿主的槽位，就能把标签条放到 Claude Code 的开关位置；没有这类插件时顶行退回宿主原样（桌面布局里整行不画）。
- 座位节点在整代生命周期里保持同一个元素，因为 React portal 认一次节点；宿主重渲染把它摘掉时放回原节点，不新建。
- 桌面壳隐藏侧栏时由探出接管打开动作，`toggleSidebar()` 仍是唯一打开路径，页面为打开的侧栏让位的逻辑不变。
- 顶行没有品牌之后，web 布局的顶行只剩标签条与折叠按钮；Windows 标题栏按钮仍固定在标题栏左上，不受影响。
- 探出不再让整个对话区重排：性能开销集中在侧栏自身的挂载与一点合成层动画上，页面隐藏时没有遗留的过渡或测量。
- 侧栏列成为定位祖先会改变列内后代的 offsetParent；宿主目前没有依赖这一层的绝对定位子节点，宿主升级后需复核。

## 重审条件

- 宿主提供标题栏下这一行的槽位，或给侧栏顶行一个官方扩展位时，改用宿主槽位，座位与 portal 契约一并撤下。
- 宿主让折叠按钮在展开与隐藏两种状态落成同一个节点时，探出的两个触发点合并成一条读取。
